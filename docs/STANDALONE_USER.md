# mtock 단독 실행판 — 사용자 안내

## 제품 원칙

- **외부 서비스 없음** — Supabase, Vercel, Google 계정, 판매자 서버 불필요
- **데이터는 이 PC에만** — 브라우저 저장 + JSON 백업
- **API 키 없이도** 매매·손익·판단 사용 가능 (시세는 Yahoo 자동 조회, 실패 시 수동 입력)
- **PC↔다른 기기** — JSON 내보내기/가져오기 (카톡·메일·USB 등 본인이 선택). 자동 클라우드 동기화 없음

## 필요한 것

- **Windows 10/11**
- **Node.js 20 이상** ([nodejs.org](https://nodejs.org) LTS 설치)
- 시세·뉴스 자동 조회 시 **인터넷** (없어도 매매 기록·손익은 가능, 시세는 수동)

## 실행 방법

1. ZIP 압축을 풉니다.
2. **`START.bat`** 을 더블클릭합니다.
3. 최초 실행 시 `npm install`과 빌드가 자동으로 진행됩니다 (2~5분).
4. 브라우저가 `http://localhost:3000` 으로 열립니다.

종료: 검은 창에서 **Ctrl+C** 후 창을 닫습니다.

## 첫 실행

- **빈 포트폴리오로 시작** — 본인 매매부터 입력
- **샘플로 먼저 체험** — 데모 데이터로 기능 확인

## API 키 (선택 · 이 PC 파일에만 저장)

| 없을 때 | 있을 때 |
|---------|---------|
| Yahoo 시세, RSS 뉴스, 매매·손익·판단 | KIS 수급·발굴, DART 공시, 거시 지표 강화 |

설정 탭 → **API 키 (선택)** → `data/local-secrets.json` (외부 서버로 전송되지 않음)

## 데이터 백업 · 다른 기기로 옮기기

1. 설정 → **JSON 내보내기**
2. 폰/다른 PC로 파일 전송 (카카오톡, 이메일, USB 등 — **본인이 쓰는 방법**)
3. 그 기기에서 mtock 실행 후 **JSON 가져오기**

※ 자동 동기화·Google 연동은 제공하지 않습니다 (외부 서비스·장애 리스크 없음).

## 모바일

- 이 판은 **PC에서 `START.bat` 실행**이 기본입니다.
- 모바일에서 보려면 JSON을 가져온 뒤 **같은 PC의 브라우저**를 쓰거나, 차기 버전의 **QR/파일 옮김** 기능을 이용하세요.

## 문제 해결

| 증상 | 조치 |
|------|------|
| START.bat 실행 안 됨 | Node.js 설치 후 PC 재부팅 |
| 빌드 실패 | 관리자 권한 없이 일반 폴더(바탕화면 등)에 설치 |
| 시세 안 나옴 | 종목 편집 6자리 코드 · 수동 시세 입력 |
| 강추!! 탭 비어 있음 | KIS API 키 입력 (선택) |
